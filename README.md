# 🎬 КиноОценка

Личный сайт для оценки фильмов: поиск любых фильмов и сериалов
(новинки и старые), оценки от 0.5 до 10 с шагом 0.5, отзывы,
фильтры по тегам и рейтингам, рейтинги Кинопоиска и IMDb.

Работает как обычный сайт **и** как Telegram Mini App.
Статический (без сборки), хостится бесплатно на GitHub Pages.

---

## 🆕 Что нового в v2

- **Два источника данных**: основной — Кинопоиск (`kinopoisk.dev`, работает из РФ без VPN),
  резервный — TMDB (подхватывается автоматически при сбое). Плюс кэш ответов:
  даже при полном отсутствии сети последние результаты открываются.
- **Рейтинги Кинопоиска и IMDb** на карточках и страницах фильмов.
- **Оценки с шагом 0.5** — клик по левой половине звезды даёт x.5.
- **Теги типов**: фильм / сериал / мультфильм / аниме / мультсериал / ТВ-шоу.
- **Фильтры**: в поиске (тип, минимальный рейтинг, годы, сортировка по популярности/
  рейтингу/году), в «Моем списке» (название, тип, диапазон своей оценки, сортировки).
- **Счётчик результатов и пагинация**.
- **Telegram Mini App**: вход по Telegram-личности (без ников), кнопка «Назад»,
  MainButton «Сохранить», вибро-отклик; старые оценки по нику склеиваются с профилем.
- Поиск работает одинаково хорошо на русском и английском.

> **Обновление с v1:** перед первым входом после обновления выполните
> `supabase/migration.sql` в Supabase SQL Editor — без этого сохранение
> оценок будет возвращать ошибку. Скрипт идемпотентен (повторный запуск безопасен).

## ⚙️ Настройка (3 шага, ~10 минут)

### Шаг 1. Ключ TMDB (поиск фильмов и постеры)

1. Зарегистрируйтесь на https://www.themoviedb.org/signup (бесплатно)
2. Откройте https://www.themoviedb.org/settings/api и запросите API-ключ
   (выберите «Developer», заполните любую форму — одобрение мгновенное)
3. Скопируйте **API Key (v3 auth)** и вставьте его в файл `js/config.js`:
   ```js
   TMDB_API_KEY: "ваш_ключ_здесь",
   ```

### Шаг 2. Supabase (общее хранение оценок)

> Если пропустить этот шаг — сайт всё равно будет работать,
> но оценки будут храниться только в вашем браузере (localStorage).

1. Зарегистрируйтесь на https://supabase.com (бесплатно, можно через GitHub)
2. Создайте новый проект (пароль и регион — любые; ждите ~1 минуту)
3. В меню проекта откройте **SQL Editor → New query**, вставьте всё
   содержимое файла `supabase/schema.sql` и нажмите **Run**
4. Откройте **Project Settings → API** и скопируйте:
   - **Project URL** → в `SUPABASE_URL` в `js/config.js`
   - **anon public** ключ → в `SUPABASE_ANON_KEY` в `js/config.js`

### Шаг 3. Публикация на GitHub Pages

1. Создайте пустой репозиторий на https://github.com/new (например `movie-ratings`)
2. В корне проекта выполните:
   ```bash
   git init && git add -A && git commit -m "КиноОценка"
   git branch -M main
   git remote add origin git@github.com:ВАШ_НИК/movie-ratings.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → Save
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://ВАШ_НИК.github.io/movie-ratings/`

## 📁 Структура

```
index.html          — страница приложения
css/style.css       — стили (тёмная тема)
js/config.js        — ВАШИ ключи (TMDB, Supabase)
js/tmdb.js          — клиент TMDB API (поиск, новинки, детали)
js/store.js         — хранение оценок (Supabase или localStorage)
js/app.js           — логика приложения и роутинг
supabase/schema.sql — SQL-схема таблицы оценок
```

## 💡 Как пользоваться

- **Главная** — новинки кино и популярные фильмы
- **Поиск** — любой фильм за всю историю кино
- Клик по звёздам на карточке — быстрая оценка; на странице фильма —
  оценка + отзыв
- **Мой список** — все ваши оценки со средней оценкой
- Ник для подписи оценок запрашивается при первом сохранении

## Безопасность

- **RLS по подписи Telegram**: клиент шлёт `x-tg-init` (подписанные Telegram'ом initData),
  Postgres проверяет HMAC-SHA256 (pgcrypto) и пускает к строкам только владельца.
  Миграция: `supabase/migration-security.sql
3. supabase/migration-watchlist-chili.sql — колонка chili (перцы чили 🌶) в watchlist` (там же блок аварийного открата).
- Веб-режим (вне Telegram): случайный ключ браузера `x-web-key`, колонка `web_key`;
  доступ только с того же браузера. Старые никовые строки недоступны by design.
- **CSP** в index.html: сторонние скрипты запрещены (`script-src 'self' + telegram.org`),
  соединения только к нашим API и Supabase.
- Порядок миграций: `schema.sql` → `migration.sql` → `migration-watchlist.sql`
  → `tg-webhook.sql` → `migration-security.sql`.
